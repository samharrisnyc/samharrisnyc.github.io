# AGENTS.md

Guidance for future agents working on this portfolio repo.

## Project Scope
- This is Samuel Harris's existing static portfolio site, published from this repo.
- Do not replace the portfolio with a new build or framework.
- Keep the current visual style: restrained editorial layout, warm paper background, thin rules, mono labels, serif headings, and compact project presentation.
- Do not delete existing projects unless Samuel explicitly asks.

## Files To Inspect First
- `index.html`
- `about.html`
- `css/styles.css`
- `js/main.js`
- `assets/docs/Samuel_Harris_Resume.pdf`

## Editing Guidelines
- Keep changes small, focused, and easy to review.
- Prefer semantic HTML and accessible native controls.
- Preserve keyboard support for the project tabs.
- Improve responsiveness by adapting the current layout instead of redesigning it.
- Keep copy concise and hiring-focused.
- Avoid unused CSS and organize styles by active page/component.
- Leave unrelated local files such as `.DS_Store` alone.

## Verification
- Check desktop and mobile widths after visual changes.
- Confirm navigation, project tabs, outbound project links, email, GitHub, LinkedIn, and resume links still work.
- Confirm keyboard focus states are visible.
- Confirm the resume action clearly opens or downloads the PDF.
